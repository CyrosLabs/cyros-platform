# ADR-0004 — FastAPI as Backend Framework

Status: Accepted

## Context

Cyros products require a modern backend framework with excellent developer experience, strong typing, automatic API documentation, and seamless AI integration.

## Decision

Use FastAPI as the primary backend framework.

## Consequences

Positive

- Excellent developer experience.
- Automatic OpenAPI documentation.
- Strong typing with Pydantic.
- High performance.
- Native Python ecosystem for AI.

Negative

- Smaller ecosystem than some enterprise frameworks.

## Alternatives Considered

- Spring Boot
- Django
- Express.js
- NestJS
