# ADR-0012 — Documentation as Code

Status: Accepted

## Context

Documentation often becomes outdated when managed separately from source code.

## Decision

Treat documentation as a first-class artifact within the repository.

Documentation follows the same engineering practices as source code:

- Version controlled.
- Reviewed.
- Maintained.
- Updated through Pull Requests.

## Consequences

Positive

- Documentation evolves with the codebase.
- Better onboarding.
- Improved engineering culture.

Negative

- Requires discipline.

## Alternatives Considered

- External wiki.
- Separate documentation repository.
- Ad hoc documentation.
