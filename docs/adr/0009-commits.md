# ADR-0009 — Conventional Commits

Status: Accepted

## Context

A consistent commit history improves readability and enables future automation.

## Decision

Adopt Conventional Commits.

Examples:

feat:

fix:

docs:

test:

refactor:

ci:

build:

## Consequences

Positive

- Better history.
- Automated changelogs.
- Semantic versioning support.

Negative

- Small learning curve.

## Alternatives Considered

- Free-form commits.
