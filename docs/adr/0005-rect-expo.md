# ADR-0005 — React Native + Expo

Status: Accepted

## Context

Cyros products should target multiple platforms while maintaining a single codebase whenever practical.

## Decision

Use React Native with Expo for mobile application development.

## Consequences

Positive

- Cross-platform development.
- Excellent developer experience.
- Large ecosystem.
- Future web support.

Negative

- Some native features may require custom development.

## Alternatives Considered

- Flutter
- Native Android
- Native iOS
