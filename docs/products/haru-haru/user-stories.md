# Haru Haru User Stories

## Account

### Create Account

As a learner,

I want to create an account,

so that my progress is saved.

Acceptance Criteria:

- User can register.
- User can login.
- User session persists.

---

# Learning

## Start Learning Korean

As a beginner,

I want to start from the correct level,

so that I don't feel overwhelmed.

---

## Learn Hangul

As a beginner,

I want to learn Korean characters,

so that I can read Korean words.

---

## Study Vocabulary

As a learner,

I want interactive flashcards,

so that I can remember words easier.

---

## Listen To Pronunciation

As a learner,

I want audio examples,

so that I learn correct pronunciation.

---

## Test Knowledge

As a learner,

I want quizzes,

so that I know what I learned.

---

## Review Mistakes

As a learner,

I want to review incorrect answers,

so that I improve my weaknesses.

---

# Motivation

## Maintain Streak

As a learner,

I want to track my daily progress,

so that I stay motivated.

---

## Unlock Lessons

As a learner,

I want progression,

so that learning feels rewarding.

---

# Premium

## Upgrade Account

As a learner,

I want premium content,

so that I can continue my Korean journey.
