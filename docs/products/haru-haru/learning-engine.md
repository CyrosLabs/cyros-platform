# Haru Haru Learning Engine

## Purpose

The Learning Engine manages how users progress through Korean learning content.

Its goal is to maximize retention, confidence, and long-term learning.

---

# Learning Philosophy

Haru Haru follows these principles:

- Learn progressively.
- Practice consistently.
- Review intelligently.
- Reward progress.

---
