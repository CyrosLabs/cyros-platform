# Sample Onboarding Guide — Documentation Agent

Welcome to the Cyros Labs Documentation onboarding guide.

This file is a short example of the type of onboarding guides the Documentation Agent should add under docs/onboarding/.

## Purpose

Provide new contributors and agents with quick start steps, repository structure, doc contribution guidelines, and contacts.

## Quick Start

1. Read the project README at the repository root for high-level goals.
2. Run local docs preview (example):
   - Install dependencies (if docs site uses a static site generator).
   - Run `npm run docs:dev` or the repo's equivalent.
3. Add new docs under `docs/` and reference them from the sidebar/navigation configuration.

## Repo Structure (docs-relevant)

- docs/ — top-level documentation site and content
- docs/onboarding/ — onboarding guides for teams and new contributors
- .ai/agents/ — agent role definitions and playbooks

## Contribution Guidelines

- Write clear, concise guides aimed at the target audience.
- Prefer examples and step-by-step instructions for onboarding.
- Add metadata (title, summary) at the top of the doc when applicable.
- Link to related engineering or product docs to avoid duplication.

## Contacts

- Documentation Engineer
- Product Owner
- Tech Lead
