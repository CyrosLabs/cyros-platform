# Glossary

This glossary collects the recurring terms used across the Cyros Labs documentation.

## Platform

A shared layer of capabilities consumed by products.

## Product

An end-user experience built to solve a specific aspect of daily life.

## Monorepo

A single repository that contains multiple apps, platform services, packages, and documentation.

## ADR

Architecture Decision Record. A document that captures the reasoning behind an important architectural decision.

## MVP

Minimum Viable Product. The first release scope intended to validate the core experience.

## TOPIK

The Test of Proficiency in Korean, which is the target proficiency framework for Haru Haru.

## Platform-first

An architectural approach in which shared capabilities are built once and consumed by multiple products.

## Streak

A user engagement concept that rewards regular daily learning activity.

## Premium Content

Content or features that require a paid subscription or purchase.
